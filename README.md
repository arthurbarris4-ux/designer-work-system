# Designer Work System

Sistema simples para organizar posts, clientes, artes, tarefas, lembretes e relatórios.

## Rodar localmente

```bash
npm install
npm start
```

Depois abra:

```txt
http://localhost:3333
```

## Deploy gratuito

Use Render + Supabase. O passo a passo está em:

```txt
README_DEPLOY.md
```
